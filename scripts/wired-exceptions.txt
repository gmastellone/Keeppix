# Functions and routes that exist without a production consumer.
# Format: fn|route <name> <phase>
#
# Two sections, declared:
#   Rinvii — the consumer lives in a phase that has not run yet.
#            <phase> is that future phase (or ops/ci).
#   Debiti — shipped in a phase that already closed, with no consumer.
#            <phase> is the phase that will pay the debt, NOT the origin.
#            Origin is in the comment on the line.
#
# A name with no consumer and no entry here is a defect. Do not add a
# name to silence the guard without putting it in the right section.
#
# Do not list TrashRepo::cleanup_expired or /ws|/ws/ticket: those were
# the Fase 2R3 defects this guard exists to catch (Tasks 4 and 6).
